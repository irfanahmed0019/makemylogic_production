BUILDMYLOGIC ↔ VS CODE

Build, run, prove.

Install the BuildMyLogic extension to receive the same learning task inside VS Code, run the correct local checks, submit your project folder, and get a Vibe review on the website.

Download the latest VSIX extension (v0.0.1)

Linux

Install from the terminal
code --install-extension buildmylogic-vscode-0.0.1.vsix

Or open VS Code → Extensions → ⋯ → Install from VSIX… and select the downloaded file.

Windows

PowerShell
code --install-extension .\buildmylogic-vscode-0.0.1.vsix

Or use the VS Code Extensions menu and choose Install from VSIX….

macOS

Terminal
code --install-extension ~/Downloads/buildmylogic-vscode-0.0.1.vsix

If the code command is unavailable, install it from the VS Code Command Palette: Shell Command: Install 'code' command in PATH.

After installation

1. Start a sessionStart the task on BuildMyLogic and copy the generated Session ID.
2. ConnectOpen the BuildMyLogic icon in VS Code and paste only the Session ID.
3. Build and runComplete each checkpoint in order, then click Run Tests Locally.
4. SubmitClick Submit to BuildMyLogic to send the project files for review.
